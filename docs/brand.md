# Brand

**Zusantara Core**: *Rooted here. Built for what's next.* Framework web TypeScript AI-driven dari Indonesia.

| Token | HEX | Penggunaan |
|---|---|---|
| Zusantara Teal | `#2ED3B7` | simbol utama, sorotan, prompt CLI |
| Heritage Gold | `#C89B52` | garis inti logo, aksen terbatas |
| Core Obsidian | `#0D1719` | latar gelap utama |
| Pearl White | `#F2F4F0` | wordmark di latar gelap |
| Muted Slate | `#829490` | keterangan & elemen sekunder |

- **Font:** Plus Jakarta Sans untuk web; font monospace pengguna untuk terminal.
- **Aset:** master logo, favicon, versi terminal (ANSI/monokrom), dan gambar pratinjau sosial ada di [`assets/brand`](https://github.com/melkimahdali/zusantara-core/tree/main/assets/brand).
