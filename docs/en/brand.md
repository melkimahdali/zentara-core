# Brand

**Zentara Core**: *Rooted here. Built for what's next.* An AI-driven TypeScript web framework from Indonesia.

| Token | HEX | Use |
|---|---|---|
| Zentara Teal | `#2ED3B7` | main symbol, highlights, CLI prompt |
| Heritage Gold | `#C89B52` | logo core line, limited accents |
| Core Obsidian | `#0D1719` | main dark background |
| Pearl White | `#F2F4F0` | wordmark on dark backgrounds |
| Muted Slate | `#829490` | captions & secondary elements |

- **Font:** Plus Jakarta Sans on the web; the user's monospace font in the terminal.
- **Assets:** the master logo, favicons, terminal versions (ANSI/monochrome), and social preview images are in [`assets/brand`](https://github.com/melkimahdali/zentara-core/tree/main/assets/brand).
